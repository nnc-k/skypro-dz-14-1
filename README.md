# Проект "Магазин" 

Учебный проект по Python: полноценная модель магазина с товарами, категориями, подсчетом статистики, загрузкой данных из JSON, магическими методами, наследованием, абстракцией и обработкой исключений.

## Функционал проекта

### Иерархия классов

- **BaseProduct** — абстрактный базовый класс (ABC) для всех продуктов. Описывает общие свойства (name, description, price, quantity), геттер/сеттер для цены и абстрактный метод __str__.
- **Product** (наследник BaseProduct и InitPrintMixin) — базовый класс для товаров.
- **Smartphone** (наследник Product) — смартфоны. Дополнительные атрибуты: efficiency (производительность), model (модель), memory (память), color (цвет).
- **LawnGrass** (наследник Product) — газонная трава. Дополнительные атрибуты: country (страна), germination_period (срок прорастания), color (цвет).
- **Category** — класс для описания категории товаров.
- **InitPrintMixin** — класс-миксин, который при создании любого объекта продукта автоматически выводит в консоль информацию о том, от какого класса и с какими параметрами был создан объект.

### Основные возможности и атрибуты

- **Приватные атрибуты:**
  - Product.__price — цена товара (доступна через property price).
  - Category.__products — список товаров в категории (доступен через property products).
- **Атрибуты класса Category:**
  - category_count — автоматически считает общее количество созданных категорий.
  - product_count — автоматически считает общее количество товаров во всех категориях.
- **Валидация данных:**
  - В сеттере Product.price реализована проверка: если цена меньше или равна 0, выводится сообщение «Цена не должна быть нулевая или отрицательная», а цена не меняется.
  - В Product.__init__ реализована проверка: если quantity <= 0, выбрасывается исключение ValueError с сообщением «Товар с нулевым количеством не может быть добавлен».

### Методы

- **Category.add_product(product)** — добавляет товар в категорию. Имеет защиту: если передан объект, не являющийся наследником Product, выбрасывается TypeError.
- **Category.middle_price()** — вычисляет среднюю цену всех товаров в категории. Если категория пуста, обрабатывает ZeroDivisionError и возвращает 0.
- **Product.new_product(dict)** — класс-метод (@classmethod), который создает объект Product на основе словаря с данными.
- **load_categories_from_json(file_path)** — функция для загрузки категорий и товаров из JSON-файла.

### Магические методы

- **__str__**:
  - Для Product: возвращает строку вида «Название, X руб. Остаток: X шт.».
  - Для Category: возвращает строку вида «Название, количество продуктов: X шт.» (считает общее количество всех единиц товара на складе).
- **__add__** (в Product): позволяет складывать два товара. Возвращает сумму произведений цены на количество у двух объектов. Защищено проверкой type(): складывать можно только товары одного класса, иначе выбрасывается TypeError.
- **__repr__** (в InitPrintMixin): возвращает строковое представление объекта для вывода в консоль при его создании.

- Python 3.14

## Установка и запуск

### Установка зависимостей
poetry install --no-root

### Запуск тестов с покрытием
poetry run pytest

Отчёт о покрытии в HTML создаётся в папке htmlcov/. Открыть отчёт: htmlcov/index.html.

### Проверка кода линтерами
poetry run flake8 src tests
poetry run black --check src tests
poetry run isort --check-only src tests
poetry run mypy src
