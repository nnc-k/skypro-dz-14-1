Учебный проект по Python: описание товаров и категорий товаров с подсчётом статистики, загрузкой данных из JSON, магическими методами, наследованием и абстракцией.

## Функционал проекта

### Классы

- **BaseProduct** — абстрактный базовый класс (ABC) для всех продуктов. Описывает общие свойства (name, description, price, quantity) и абстрактный метод `__str__`.
- **InitPrintMixin** — класс-миксин, который при создании объекта печатает в консоль его класс и переданные параметры.
- **Product** (наследник BaseProduct и InitPrintMixin) — описывает товар.
- **Smartphone** (наследник Product) — смартфон. Дополнительные атрибуты: efficiency, model, memory, color.
- **LawnGrass** (наследник Product) — газонная трава. Дополнительные атрибуты: country, germination_period, color.
- **Category** — категория товаров.

### Методы и магические методы

- **Category.add_product(product)** — добавляет товар с проверкой типа (isinstance).
- **Product.new_product(dict)** — classmethod, создаёт объект из словаря.
- **Product.__str__** — «Название, X руб. Остаток: X шт.».
- **Product.__add__** — сложение двух товаров с проверкой type(): только объекты одного класса.
- **Category.__str__** — «Название, количество продуктов: X шт.».
