# Домашнее задание 15.1

Учебный проект по Python: описание товаров и категорий товаров с подсчётом статистики, загрузкой данных из JSON и магическими методами.

## Функционал проекта

### Классы

- **Product** — описывает товар:
  - name — название товара;
  - description — описание;
  - price — цена (с копейками, приватный атрибут);
  - quantity — количество в наличии (в штуках).

- **Category** — описывает категорию товаров:
  - name — название категории;
  - description — описание;
  - products — приватный список объектов Product.

### Атрибуты класса Category

- **category_count** — общее количество созданных категорий;
- **product_count** — общее количество товаров во всех категориях.

Оба атрибута заполняются автоматически при инициализации объекта Category и при добавлении товара через add_product.

### Методы

- **Category.add_product(product)** — добавляет товар в категорию и увеличивает product_count.
- **Product.new_product(dict)** (classmethod) — создаёт объект Product из словаря.

### Геттеры и сеттеры

- **Product.price** — геттер и сеттер цены с проверкой: если значение ≤ 0, выводится сообщение «Цена не должна быть нулевая или отрицательная», цена не меняется.
- **Category.products** — геттер приватного списка товаров, возвращает строку со всеми товарами.

### Магические методы

- **Product.__str__** — строковое представление товара: «Название, X руб. Остаток: X шт.».
- **Product.__add__** — сложение двух товаров: сумма произведений цены на количество (price × quantity).
- **Category.__str__** — строковое представление категории: «Название, количество продуктов: X шт.», где X — суммарное количество всех товаров на складе.

### Дополнительный функционал

- **load_categories_from_json(file_path)** — функция, которая читает JSON-файл и создаёт на его основе объекты классов Category и Product. Возвращает список категорий.

## Установка и запуск

### Установка зависимостей

poetry install --no-root

### Запуск тестов с покрытием

poetry run pytest

Отчёт о покрытии в HTML создаётся в папке htmlcov/. Открыть отчёт: htmlcov/index.html.

### Проверка кода линтерами

poetry run flake8 src tests
poetry run black --check src tests
poetry run isort --check-only src tests
poetry run mypy src
